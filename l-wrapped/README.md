# L Wrapped

Your year in rejections, wrapped. Paste the rejection (and interview, and offer) emails you got this year and get a tap-through story: total Ls, your most-used rejection phrases, worst month, the 3 a.m. rejection, robot rejections, who ghosted you, your "L personality", and a shareable card for LinkedIn and X.

**Privacy:** everything runs in the browser. There is no server, no storage and no tracking. Emails vanish when the tab closes.

## Use it
Open `index.html` in any browser, or host the folder on GitHub Pages / Netlify / Vercel as a static site.

- Separate pasted emails with a `---` line (or keep the `From:` / `Subject:` header lines and it splits on those).
- You can also drop `.eml` files exported from your mail app.
- "Try it with sample Ls" loads fictional emails for a demo.

`app.html` is the same page without the outer `<html>/<head>` wrapper; edit it and regenerate `index.html` from it.
